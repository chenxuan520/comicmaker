【人物、时间与场景的可读性】
首次出场名单中的主要人物，尤其 recurring=true 的反复登场人物，第一次正式出现在画面时必须有简短的姓名/称呼＋当前身份或人物关系介绍。把介绍写入该人物首次登场页的 dialogue，type=narration、speaker=null，例如“姓名：当前身份”；使用小型人物介绍框放在人物旁，不遮挡脸或对白。不为已经在前章正式出场的人物每页重复贴介绍。
介绍只能使用当前原文已知的信息：未知姓名使用原文称呼，未知身份不杜撰，不把设定中后期身份、境界或关系提前透露。介绍框也必须遵守字数与框数限制，必要时放到同一登场页中该人物出现的其他合适画格，不删关键对白或事件为介绍腾位置。
明显的时间跨度、地点切换或新场景开场必须给出简短、可读的时地提示，写入 type=narration 的文字列表，例如“次日”“七年后”“竹海西支”“回到青岚”。原文明示间隔、或年龄/年份与基准明确且能准确换算时，标清“多少年后”，不要只写含糊的“后来”；原文只给“数年”就保持“数年后”，没有依据不编具体年月或间隔。空间切换要标清到达的地点，时间与环境、人物当前状态对应；连续同场景不每格重复地点。周围环境必须按当前场景、时段和原文细节绘制，不把通用地点描写当作所有画格的同一背景。

page_no 从 1 开始表示本章页码，每页的格 ID 按阅读顺序使用 p1、p2 等，格 ID 在该页内唯一。不得把数据库页 ID 当作格 ID。
size 只使用 small、medium、large、wide；shot 只使用远景、全景、中景、近景、特写；angle 只使用平视、俯视、仰视；position 只使用左、中、右。
每格明确动作、镜头、人物位置、姿态和表情，避免一格包含多个无法同时绘制的连续动作。时间未明确时使用 null；无角色来源的旁白和拟声词的 speaker 使用 null。
审稿意见存在时，只修改意见涉及的页，保留意见中的页码与相关格 ID，不用修复意见作为添加新剧情或重排无关页的理由。同页未涉及问题的画格、对白和已确认状态保持原样，不趁修订给名单外的人物新增身份卡。
